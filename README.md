## 🚀 What I'm working on

### AwakenDev
I'm a co-founder and primary software developer at **AwakenDev**, where I'm building and deploying a retail point-of-sale platform designed for real-world shops.

The platform includes:
- Multi-shop retail POS workflows
- Product and inventory management
- Barcode scanning
- Sales, customer credit, suppliers and quotations
- FIFO-based stock and cost handling
- Business, tax and inventory reporting
- Role-based access control and audit logging
- Database backups, exports and production deployment

The application is built with **Laravel, PHP, Blade, JavaScript, MySQL/MariaDB, Vite, Redis and Docker** and uses a multi-tenant architecture with separate master and shop-specific databases.
